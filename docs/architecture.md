## Что должно уметь приложение

1. Программа запускается на Windows.
2. Пользователь вводит данные от роутера, который прошит OpenWrt по инструкции.
3. Программа подключается к роутеру.
4. Проверяет установку sing-box и его версию.
5. Проверяет подключение к интернету.
6. Если sing-box отсутствует - устанавливает нужную версию.
7. Производит настройку и создает нужные для работы скрипты.
8. Требует ссылку по которой происходит подключение к ВПН, либо запрашивает ввод данных от ВПН по отдельности.
9. После этого происходит проверка и сохранение конфигураций.
10. Пользователь выбирает какие сайты будут работать с ВПН.
11. Программа требует по очереди заходить на каждый сайт/приложение для окончательной проверки и настройки ВПНа.
12. Программа показывает статус подключения, сайты работающие с ВПН, позволяет добавить новый, удалить один из добавленных,показывает пинг, добавить или заменить данные ВПН, переключиться между ВПН аккаунтами.
