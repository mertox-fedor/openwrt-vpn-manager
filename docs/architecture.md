# Архитектура проекта

## Что должно уметь приложение

Программа запускается на Windows.
Пользователь с вводит данные от роутера, который прошит OpenWrt по иструкции.
Программа подключается к роутеру.
Проверяет установку sing-box и его версию.
Проверяет подключение к интернету.
Если sing-box отсутствует - устанавливает нужную версию.
Производит настройку и создает нужные для работы скрипты.
Требует ссылку по которой происходит подключение к ВПН, либо запрашивает ввод данных от ВПН по отдельности.
После этого происходит проверка и сохранение конфигураций.
Пользователь выбирает какие сайты будут работать с ВПН.
Программа требует по очереди заходить на каждый сайт/приложение для окончательной проверки и настройки ВПНа.
Программа показывает статус подключения, сайты работающие с ВПН, позволяет добавить новый, удалить один из добавленных, показывает пинг, добавить или заменить данные ВПН, переключиться между ВПН аккаунтами.
